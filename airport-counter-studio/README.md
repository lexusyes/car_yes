# 櫃檯配置室 · Airport Counter Studio

可在瀏覽器操作的機場櫃檯與排隊動線平面圖編輯器，使用繁體中文介面。

## 功能

- CTR 櫃檯寬兩個粗格，編號與用途各高一格。
- 橫向八格長線、直向一格短線，可拖曳調整長度。
- 粗格線吸附、端點定位、四方向直角旋轉。
- 櫃檯、文字、功能區、直箭頭、彎箭頭、三角形與設施可改色。
- 框選、多選、群組移動、複製、刪除與復原。
- 五組參考圖模板、延伸空白頁。
- 配置 JSON 下載與載入、PNG 輸出及瀏覽器列印。

## 使用

不需要安裝套件或建置。將 `index.html` 與 `app.js` 放在同一個靜態網站目錄即可。

本機預覽：

```sh
python3 -m http.server 8000
```

在瀏覽器開啟 `http://localhost:8000`。

## 手機操作

手機會顯示符合螢幕寬度的畫布。若手機瀏覽器顯示桌面版，可按上方「手機介面」手動切換。

- 底部固定提供橫線、直線、復原及複製，另有素材／模板、畫布、屬性／顏色分頁。
- 瀏覽模式可滑動圖面；移動模式可拖曳素材；調整模式才顯示縮放與旋轉控制點。
- 用 ＋／− 調整縮放，或按「適合」恢復符合螢幕寬度。
- 上方頁面工具可快速切換頁面及刪除空白頁。有素材的頁面不會被刪除。
- 屬性面板提供手機多選、靠左／頂端對齊及水平／垂直等距排列。群組會整組排列。
- 在屬性面板選擇輸出範圍，可輸出完整頁面或僅輸出有內容範圍。PNG 去除外圍留白，PDF 內容模式略過空白頁。

## 資料儲存

配置自動儲存在目前瀏覽器的 localStorage，未同步至雲端。換裝置前，請先下載配置 JSON 備份。

圖面為示意配置，非現場測繪尺寸。PDF 使用瀏覽器的列印功能，實際結果依瀏覽器設定而異。
